# Foodstore - Recuperatorio Parcial 2

Sistema integral de gestión de catálogo de alimentos compuesto por una API REST en el backend y una interfaz web en el frontend.

Alumno: Mauro Cuquejo  
Materia: Programación 4  
Carrera: Tecnicatura Universitaria en Programación y Administración de Datos  

## Estructura del proyecto

- `foodstore-backend/`: API REST desarrollada con FastAPI, SQLModel y base de datos PostgreSQL.
- `foodstore-frontend/`: Cliente web desarrollado con React, TypeScript, Vite y Tailwind CSS.

## Puesta en marcha

1. Iniciar la base de datos y la API siguiendo los pasos detallados en `foodstore-backend/README.md`.
2. Iniciar el frontend siguiendo los pasos detallados en `foodstore-frontend/README.md`.

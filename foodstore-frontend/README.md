# Foodstore Frontend

Aplicación web desarrollada con React, TypeScript, Vite y Tailwind CSS para la administración de productos.

Alumno: Mauro Cuquejo  
Materia: Programación 4  
Evaluación: Recuperatorio Parcial 2  

## Requisitos

- Node.js 18 o superior
- npm o pnpm

## Instalación y ejecución

1. Instalar las dependencias:
```bash
npm install
```

2. Ejecutar el servidor de desarrollo:
```bash
npm run dev
```

La interfaz queda disponible por defecto en:
http://localhost:5173
